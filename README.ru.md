# Photo

Локальная студия для генерации и редактирования изображений открытыми моделями
на вашей видеокарте NVIDIA RTX. Без аккаунта, облака и телеметрии: описания и
картинки не покидают компьютер.

[English version](README.md)

## Что умеет сейчас

- Генерация по описанию моделью **Z-Image Turbo** (Apache-2.0, коммерческое
  использование разрешено): 8 шагов, около 2,7 секунды на изображение
  1024×1024 на RTX 5080 (первое после запуска около 24 секунд, пока грузится модель).
- Превью шагов в реальном времени, очередь задач, отмена.
- Галерея с избранным и отменой удаления. В каждый PNG записаны точные
  параметры (стандартное поле `parameters` и полный JSON).
- Версия модели подбирается под видеокарту автоматически: NVFP4 для RTX 50,
  BF16 для RTX 40.
- Интерфейс на 12 языках: English, 简体中文, Español, Português (Brasil),
  Français, Deutsch, Italiano, Русский, 日本語, 한국어, Türkçe, العربية (справа налево).
- Тёмная, светлая или системная тема, работа с телефона в домашней сети
  (по желанию, с защитой токеном).

Дальше редактирование: дорисовка по маске, правки словами, увеличение,
удаление фона. Подробнее в [плане](docs/roadmap.md).

## Требования

| | Минимум | Рекомендуется |
|---|---|---|
| Видеокарта | NVIDIA RTX 40, 8 ГБ | RTX 4080 / серия 50, от 16 ГБ |
| Драйвер | 580 или новее | последний |
| ОЗУ | 16 ГБ | 32 ГБ |
| Диск | 25 ГБ свободно | от 100 ГБ под несколько моделей |
| ОС | Windows 10 1903+ x64 или Linux x86_64 | Windows 11 |

## Установка

**Windows**: скачайте `Photo-<версия>-windows.zip` со страницы
[Releases](../../releases), распакуйте в короткий путь, например `C:\Photo`,
и дважды щёлкните **`install.cmd`**.

**Linux**: скачайте `Photo-<версия>-linux.tar.gz`, распакуйте и запустите `./install.sh`.

Примерно через минуту подготовки в браузере откроется мастер установки:

1. **Язык**: выберите один из 12, мастер сразу переключится. Здесь же
   проверяются видеокарта и драйвер.
2. **Хранение**: выберите диск и папку для моделей, движка и галереи.
   Свободное место проверяется по каждому диску до начала загрузки.
3. **Модели**: рекомендуемая модель уже отмечена, лицензии видны сразу.
4. **Установка**: загрузки проверяются по SHA-256 и продолжаются после обрыва
   связи. В конце кнопка «Открыть Photo» переключает страницу на программу.

В систему ничего не ставится: чтобы удалить программу, удалите папку. Повторный
запуск установщика чинит установку, а если там выбрать другой диск для моделей,
файлы будут перенесены, а не скачаны заново.

Потом запускайте **Photo** ярлыком на рабочем столе, `Photo.cmd` или `./photo.sh`.
Программа откроется по адресу <http://127.0.0.1:7860>.

**Установка без участия пользователя** (скрипты, серверы без рабочего стола):

```powershell
install.ps1 -Unattended -Language ru -ModelsDir D:\Photo\models -EngineDir D:\Photo\engine
```
```sh
./install.sh --unattended --language ru --models-dir /mnt/data/photo/models
```

Если Hugging Face открывается медленно или заблокирован, перед установкой
укажите зеркало: `set PHOTO_HF_ENDPOINT=https://hf-mirror.com`.

## Лицензия

Photo распространяется под Apache-2.0. У каждой модели своя лицензия, она
указана на странице «Модели». Что можно делать с созданными изображениями,
зависит от модели, которой они сделаны.
